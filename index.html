chaffed's OpenWrt packages

A package source for OpenWrt and GL.iNet routers.

PackageWhat it does
luci-app-ispyScheduled speed tests, a dashboard, and a report comparing what your ISP delivers with what it advertises.
luci-app-modemhealthWatches your cable modem (SURFboard S33/S34): signal, errors, dropouts and outages, with a report for your ISP.

Add the source (once)

Over SSH on the router:

wget -O /tmp/chaffed.pub https://chaffed.github.io/openwrt-packages/chaffed.pub
opkg-key add /tmp/chaffed.pub
echo 'src/gz chaffed https://chaffed.github.io/openwrt-packages' >> /etc/opkg/customfeeds.conf
opkg update

The key lets the router check the package list came from here (fingerprint e657e1c1cfd7d36d).

Install

opkg install luci-app-modemhealth luci-app-ispy

Updates then arrive with opkg upgrade or LuCI's System → Software. Works with OpenWrt 21.02–24.10 and GL.iNet firmware 4.x. Source and details.
